Set up Matter Workspace

Download the skill, add it to an assistant that can work with files, and start in the shared folder for a legal matter.

Download version 1.5.1 ZIP

Before using it with a matter: Review the ZIP and confirm that your firm permits the assistant and the selected folder or connector to handle that matter’s information. The skill will ask for context and approval before changing an existing workspace.

Claude

  1. In Claude, open Customize → Skills. Enable code execution and skills if your account or organization requires it.
  2. Choose + → Create skill → Upload a skill, then select the ZIP. Turn on Matter Workspace in your skills list.
  3. Open the legal matter folder in a file-capable Claude session and ask: “Use Matter Workspace to set up this matter folder.”

Your organization may control whether custom skills or file access are available. Claude skill instructions.

Codex

  1. Unzip the download. Confirm that it contains one matter-workspace folder with SKILL.md, templates, and references.
  2. Place that folder in your user skills directory: ~/.agents/skills/matter-workspace/. If you use a repository-specific setup, place it in that repository’s .agents/skills/ directory instead.
  3. Open the legal matter folder as your Codex working directory and ask: “Use $matter-workspace to set up this matter folder.” If the skill does not appear, restart Codex.

OpenAI skill instructions. Local standalone skills are supported in the ChatGPT desktop app, Codex CLI, and IDE extension; other ChatGPT surfaces have different distribution options.

What to expect

The skill first checks the folder and any existing team setup. For a new matter, it asks a short set of setup questions. For an older workspace, it shows a proposed change plan before moving or replacing files. After setup, start a fresh session from the matter folder so its instructions load.

It organizes a shared workspace; it does not learn the case record for you. Keep human review over matter facts, confidentiality, and any external communication. The skill is available under the MIT License.
