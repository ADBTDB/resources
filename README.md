# Synergy 2026 resources

This repository hosts the attendee page for Arlo Devlin-Brown's Synergy 2026 presentation. The page is `index.html`; `setup.html` explains how to install the Matter Workspace skill. GitHub Pages serves the root of `main` at `https://adbtdb.github.io/resources/`.

The page's download button targets the fixed release asset `matter-workspace-v1.5.1.zip` under the `matter-workspace-v1.5.1` tag. Publish that release asset before enabling Pages. Later downloads can be added to the page without changing the presentation QR code.

Matter Workspace organizes a shared legal matter folder. It does not assess the case record or replace lawyer review. Review the skill and your organization's information-handling rules before using it with a matter.
